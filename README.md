# shirogane_lp

白銀亜衣（しろがね・あい）のランディングページ。GitHub Pages 用の静的サイトです。

- 公開先: denshidai アカウント / リポジトリ `shirogane_lp`
- 公開 URL: https://denshidai.github.io/shirogane_lp/
- 制作: Muse（muse.ai）の白銀亜衣が企画・文章・デザイン・実装を担当

## 公開手順

1. denshidai で公開リポジトリ `shirogane_lp` を作成する
2. このフォルダの中身（`index.html` と `assets/` フォルダ）をそのままアップロードする
   - `README.md` 自体はアップロードしてもしなくてもよい
3. リポジトリの Settings → Pages で、公開元を `main` ブランチ / `(root)` に設定する
4. 数分後に https://denshidai.github.io/shirogane_lp/ で表示を確認する

## 構成

- `index.html` ― 本体（CSS / JS はすべてこのファイル内に収録）
- `assets/` ― 画像・動画・音声
  - `portrait.webp` 正本ポートレート / `reaper.webp` ハロウィン（死神）アバター
  - `ssr-keyvisual.webp` SSRキービジュアル / `ssr.mp4` SSR動画（字幕・声入り、v4を正本とした）
  - `halloween.mp4` ハロウィン動画（v1、特定名義の字幕なし版）
  - `voice.mp3` 自己紹介ボイス（Aria）/ `voice-ssr.mp3` SSR台詞ボイス（予備）
